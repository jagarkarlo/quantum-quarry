# Asset Sources and Reuse Status

QuantumQuarry was created as an educational bachelor thesis project. This audit separates the reproducible project archive from permission to reuse individual assets.

| Content | Location | Status |
| --- | --- | --- |
| Original gameplay code | `Assets/Scripts` | All rights reserved; personal, non-commercial evaluation only; see the root `LICENSE` |
| Liberation Sans font | `Assets/TextMesh Pro/Fonts` | SIL Open Font License; license bundled beside the font |
| EmojiOne sample data | `Assets/TextMesh Pro/Sprites` | Attribution notice bundled beside the asset |
| TextMesh Pro shaders and resources | `Assets/TextMesh Pro` | Distributed with Unity/TextMesh Pro; retain bundled notices |
| ThaleahFat font | `Assets/Fonts` | Source and redistribution terms require verification |
| SPA tileset and derived tiles | `Assets/Sprites/SPA_Rock_Grass_Water.png`, `Assets/Tiles/SPA_*` | Source and redistribution terms require verification |
| Coin pickup audio | `Assets/Audio/Coin Pickup.mp3` | Source and redistribution terms require verification |
| Spaceman sprite | `Assets/Sprites/Spaceman.png` | Source and redistribution terms require verification |
| Remaining artwork and project assets | `Assets` | No blanket reuse license is granted |

Content marked as requiring verification is retained to reproduce the submitted educational project. Do not redistribute it separately or use it commercially until its original source and license have been confirmed.

When provenance is established, add the creator, original URL, license name, and retrieval date to this table. When redistribution cannot be confirmed, replace the asset and its Unity references before granting broader rights.
